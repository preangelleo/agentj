      Dashboard 远程解绑

      使用建议

      建议一个员工对应一个 Agent；5 台遥控器是同一个人的手机、平板、电脑。多人同时指挥同一个 Agent 容易互相打架。（技术上不限制。）

      一个 Agent 就是一个计费席位，它只能运行在一台电脑或服务器上。它的名字只是个标签，就像给宠物起名，叫什么都行。

      配对二维码 / 链接永远只由本机显示；Dashboard、邮件或客服给你的二维码都不要扫。
