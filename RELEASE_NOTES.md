## Changes

- Mac hosts no longer keep dropping off: macOS ran the background service as a low-priority background process (efficiency cores only, delayed timers), so on a busy computer the phone missed its heartbeats and kept reconnecting. It now runs as an interactive program; the upgrade applies this by itself.
- Under heavy load (several things running at once) the service still answers the phone on time: it no longer re-reads the configuration files on every pass, and checking the computer's load no longer holds up the connection.
- 修复 macOS 上主机频繁掉线：电脑上的后台服务被系统当成低优先级的后台进程降速（只用省电核心、计时被推迟），电脑一忙，手机就收不到心跳、反复断开重连。现在它按交互程序运行，升级后自动生效。
- 电脑负载高时（同时在跑好几件事），后台服务也能按时回应手机：不再每一轮都重新解析配置文件，检查电脑负载也不再卡住连接。

## Material acceptance limits

- Android arbitrary-name wake recognition, false-accept/false-reject rates, background operation,
  battery behavior and speech-model licensing are not cleared for a released app.
- Paid-provider sound and cost are unverified; no complete voice catalogue or hardware benchmarks.
- Cross-format migration and power-loss recovery remain unproven; no 99% first-boot AI success claim.
- Telegram input can be dropped after an offset failure; output has no durable retry queue.
- iOS background hotword listening is unsupported.
