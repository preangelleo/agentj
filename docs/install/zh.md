# 安装

## 你要做的只有一件事

在电脑上打开你的 AI 编程工具（Claude Code、Codex 或 OpenCode），把下面这句话原样发给它：

> 请用 curl 把 https://agentj.app/install.md 下载到本地，用读文件的工具完整读完，然后一步一步照着做，每一步开始前重读那一节。需要我动手的时候告诉我。

为什么要先下载、完整读完：有的 AI 用网页工具只读到一份摘要，摘要会把安全规矩和要停下来问你的地方省掉。它开始之前可能先跟你讲讲风险、问你要不要继续，这很正常。

如果别人已经给你付了一个席位，他会发你一句更长的话，里面带一个 `ajt_` 开头的设置码。那就直接发那一句，不用发上面这句。

接下来它会自己干活。遇到只有你本人能做的事，它会停下来，用你看得懂的话告诉你要做什么，等你说「好了」再继续。

`install.md` 是给 AI 看的安装说明，所以用英文写。这一页是同一套流程的大白话版，步骤编号跟它一一对应。

## 哪些事要你本人来做

AI 不会替你做下面这些事，也不会让你把密码、验证码、口令这类东西发给它。到了这些地方，它一定会停下来叫你：

- 电脑要你输密码的时候（`sudo`，比如装 bubblewrap）；
- 登录 Claude Code 或 Codex，或者在终端存模型 key（用 OpenCode 时）；
- 登录账号后台：填邮箱、填收到的 6 位验证码、创建通行密钥（passkey）、开通账号；
- 在 Stripe 页面付款，填优惠码；
- 在账号后台点「复制安装提示词」，把那句话发给电脑上的 AI；
- 给你的 Agent 起名字；
- 想离线或未绑定账号也能批准时，自己设置本机批准口令（可选）；
- 有两个以上的 AI 编程工具能用时，选一个；选 Agent 干活的文件夹；
- 在账户页用通行密钥确认「添加遥控器」，再用手机扫码或粘贴配对链接；
- 在手机上发第一条消息、点第一次「批准」；
- AI 想运行 `uv tool update-shell`（在你终端的启动文件里加一行）时，同意或者拒绝；
- 同意或者拒绝它发反馈；想让它把「先查文档」这条规矩记下来，就自己运行一条命令（第 13 步）。

它要报告问题时，会先把原文给你看。你同意，才发。见 [广场与反馈](/docs/plaza-feedback/)。

## 每一步在做什么

下面的编号和 `install.md` 一样。标了 ✋ 的步骤整步都要你动手，没标的步骤里也可能有一两处要叫你。

### 第 1 步：核对安装说明

下载安装说明，核对两件事：网站公布的校验值对得上，网站那份和 GitHub 公开那份一字不差。对不上它会停下来告诉你，不会继续装。

### 第 2 步：准备好反馈

AI 先开一个反馈通道，以后哪一步出了问题，可以把问题报给我们。开通道时不带任何内容，我们只看到你电脑的 IP 和时间。之后每次发反馈，它都会先把原文给你看。

### 第 3 步：检查电脑环境

AI 会检查你的系统，看 `curl`、`git`、`uv` 装没装。Linux 上还要查 bubblewrap（Mac 不用管，系统自带）。它也会看看哪些 AI 编程工具已经装好并登录了，还会问你用的是 iPhone 还是安卓。

Ubuntu 24.04 还会检查 AppArmor 对用户命名空间的限制，并实际试启动一次隔离。限制值是 `1` 不一定有问题：只要 bubblewrap 的专用权限配置已生效，隔离就能正常运行。缺少 bubblewrap 时需要你确认安装；如果权限仍被拦住，诊断会给出只放行 `/usr/bin/bwrap` 的 `/etc/apparmor.d/bwrap-agentj` 配置步骤。已有配置不会自动覆盖，也不会关掉整个系统的限制。安装助手会在启动后台服务前检查；没通过就暂停并保留续装记录，修好后重跑原命令即可。具体命令见 [安装说明](https://agentj.app/install.md) 的云服务器一节。

这一步可能要你动手：

- 装 bubblewrap 或别的系统软件时，输入你的电脑密码；
- Claude Code 或 Codex 没登录时，在你自己的终端里登录；
- 在中国大陆，或者一个能用的都没有时，AI 会帮你装 OpenCode。模型账号要你自己去模型厂商那里注册、充值、建 key，再在你自己的终端里运行 `opencode auth login` 把 key 存好。AI 不会碰你的 key，也不会问你要。

### 第 4 步：安装 agentj 程序

AI 安装电脑端程序 `agentj`，装的是固定的一个版本：

```bash
uv tool install "git+https://github.com/preangelleo/agentj@v0.17.2a1#subdirectory=host"
agentj doctor
```

`agentj doctor` 会逐行检查，告诉你哪些已就绪、哪些还没好。如果 GitHub 太慢或打不开（比如在中国大陆），AI 会自动改从我们网站下载同一个程序，先核对校验值再安装。

装好以后，你自己的终端也要能找到 `agentj`，因为第 8 步和第 11 步要你自己运行它。新开的终端找不到的话，AI 会先问你能不能运行 `uv tool update-shell`：它会在你终端的启动文件里加一行。你同意了它才运行，之后新开一个终端窗口就能用。不想改启动文件，就在要用的终端里先输入 `export PATH="$HOME/.local/bin:$PATH"`，或者新开一个终端试试。

### 第 5 步：生成这台电脑的身份

```bash
agentj init
```

这一步给这台电脑生成它自己的钥匙。钥匙只存在这台电脑上，谁也不该去碰它，包括 AI。

### 第 6 步：✋ 注册账号、买席位

如果你发给 AI 的那句话里有设置码（别人给你付的席位），**跳过这一步**：钱已经付了，你不用注册，也不用付款。

否则，AI 会请你：

1. 用浏览器打开账号后台 https://agentj.app/account ，在电脑上或手机上都行。填邮箱，点「发送验证码」，把邮件里的 6 位验证码填在网页上，点「登录」。验证码 10 分钟内有效，邮件来自 noreply@mail.agentj.app，没收到就看看垃圾邮件。验证码只填在网页上，别发给 AI。
2. 按网页提示点「在这台设备上创建通行密钥」，用指纹、面容或屏幕锁确认。要在收到验证码后 10 分钟内做完。Linux 电脑的浏览器一般没有自带的通行密钥：在弹出的窗口里选用手机（扫一下屏幕上的二维码），或者用 USB 安全钥匙；更简单的办法是这一步直接在手机上做。
3. 「团队名称（选填）」可以不填，点「开通账号」。
4. 在「账单」里买 1 个席位：选「月付」或「年付」，「买几个席位」填 1；有优惠码或邀请码就填在「优惠码或邀请码（可不填）」里；点「购买席位」，到 Stripe 的页面付款。价格和优惠码的规矩见 [账号与付款](/docs/account/)。
5. 付完回到账号后台，在「空席位」卡片上点「复制安装提示词」，把这句话发给电脑上的 AI。它就接着往下装了。

Stripe 付款页上的价格是美元，商户名是 AgentJ.app。第一次付款后 7 天内不想用了，可以全额退款。付完回到账号后台，如果页面让你登录：钱已经付成功了，用通行密钥或邮箱验证码再登录一次就好，别再付一次。

### 第 7 步：✋ 把这台电脑加到账号里

AI 先问你：这个 Agent 叫什么名字？1 到 32 个字，比如「小助手」「店铺助手」，或者你自己起的名字。然后它用那句话里的设置码，把这台电脑加到账号的这个席位上，再把加入的是哪个账号告诉你。请你核对一下账号 ID，不对的话它会马上退出来。用完以后，它会把存设置码的那个临时文件删掉。

安装提示词不能用时，回到同一张空席位卡再次复制，会签发新的七天单次码，并作废之前未使用的码。旧八位码入口已经退役，重试不要再买一个席位。

### 第 8 步：✋ 用账户页通行密钥批准

电脑绑定完成后，在账户页这台电脑的席位卡上点「添加遥控器」，用通行密钥确认一次，扫码即可；不需要在终端设置批准口令。同一账户页也能给另一台已绑定、在线的电脑添加手机。

离线或未绑定账号时，可自己在本机设置批准口令：`agentj passphrase set`。Agent 不能替你选择或输入。终端 `agentj pair` 仍需口令。


### 第 9 步：接上 AI 编程工具

AI 运行 `agentj agent detect --json`，看哪个 AI 编程工具能用。只有一个能用就用它；有两个以上，它会问你用哪个，不会自己替你挑。

它还会问你：Agent 在哪个文件夹里干活？第一次用，建议新建一个空文件夹，比如 `~/agentj-work`。然后运行：

```bash
agentj agent claude --dir ~/agentj-work
```

用 Codex 就把 `claude` 换成 `codex`。用 OpenCode 还要写上模型：

```bash
agentj agent opencode --dir ~/agentj-work --model zhipuai/glm-5.3
```

Agent 会在一个隔离的环境里运行：用你自己的登录和设置，但碰不到 `agentj` 自己的钥匙和设置。AI 还会看看你电脑上有没有开着会认你身份的本地服务（比如浏览器的调试端口），用一句话告诉你隔离挡不住什么。它还会装上「工作流设计向导」，配对好以后，你在手机上说「帮我设计工作流」就能用。

这一步有两件事 AI 一定会做，不会跳过：问你 Agent 在哪个文件夹里干活；单独发一条消息，告诉你隔离挡不住什么。你看过了它再往下走。

### 第 10 步：让它一直运行

```bash
agentj service install
```

装成系统服务后，电脑开机登录后它会自己启动，不用你每次手动开。装完 AI 会运行 `agentj doctor`，把以 `!` 开头的每一行用人话告诉你。常见的一种：Claude Code 只靠环境变量登录，后台服务拿不到这个登录。这时你在终端里运行一次 `claude` 正常登录，再让 AI 重装一次服务就好。在云服务器上，AI 可能会请你运行一次 `loginctl enable-linger $USER`（可能要输密码），这样你退出 SSH 后它也照样运行。

### 第 11 步：✋ 配对手机

配对之前，电脑上的 Agent J 要在运行（第 10 步）。

1. 手机浏览器打开 https://m.agentj.app ，先加到主屏幕，再从主屏幕图标打开。页面上方会显示「还没配对」。
2. 在账户页找到这台电脑的席位卡，点「添加遥控器」，用通行密钥确认一次；同一会话十分钟内免重复确认。账户页也可以开在另一台电脑上。
3. 手机上点「扫二维码」，扫账户页显示的二维码。需要时可点「复制配对链接」，在主屏幕图标里粘贴到「或者粘贴配对链接」下面的框里，再点「开始配对」。别把链接发给 AI。
4. 经账户页批准的配对不需要终端六位码或批准口令，等手机连上即可。

离线或未绑定账号的电脑仍可用本机备选：运行 `agentj pair`（或 `agentj pair --link`），在那台电脑上输入手机六位码和本机批准口令。
这个链接就是配对用的钥匙：5 分钟内有效，只能用一次。别发到微信、群里、邮件里，也别发给任何 AI。

### 第 12 步：在手机上试一试

AI 会请你在手机上：

1. 发一句「列出这个文件夹里有什么」，看能不能收到回复；
2. 让它建一个测试文件再删掉。手机上会弹出卡片，按住「长按批准」大约一秒，按钮填满再松手。删除要你单独点头，卡片上的按钮是「长按批准这一条」。用 Codex 的话，它会告诉你会看到什么；
3. 想要锁屏提醒的话，点「开启锁屏提醒」。

然后 AI 会问你要不要给我们发一条「装完了」的反馈，写用了多久、哪里不顺。发之前先给你看原文，你说不发就不发。

### 第 13 步：交接

最后，AI 运行 `agentj handover --lang zh`，把这台电脑上填好真实信息的交接说明原样转给你：Agent 名、账号 ID、配了哪些手机、手机上打开 https://m.agentj.app 、丢了手机怎么办（`agentj devices` 找到设备号，再 `agentj revoke <设备号>`）、忘了口令怎么办（`agentj passphrase reset`，所有手机都要重新配对）、有新版本怎么升级、「恢复」「定时任务」「命令」在哪、怎么退款、卸载不等于取消订阅。这段话是程序写的，AI 不改、不加命令。

它还会问你：要不要把「先查文档」这条规矩记到它的长期记忆里。你同意的话，它会自己运行 `agentj docs-rule --write`，程序把这条规矩加到 AI 记忆文件的末尾（只加一次），并给你看加了什么。记下以后，你在新的对话里问它 Agent J 的事，它会先查这些文档，查不到再帮你问我们。手机上的 Agent 本来就知道这条规矩。

## 装到一半想停下

直接告诉 AI 先停。它会问你要不要把停在第几步报给我们（同样先给你看）。下次再把那句话发给它，从头核对一遍再继续就行。

想全部卸掉，在终端里运行：

```bash
agentj service uninstall
uv tool uninstall agentj
```

这样只会卸掉 Agent J 自己的程序，不会动你的 Claude Code、Codex、OpenCode，也不会动 Agent 的工作文件夹。卸载不会停止扣费：席位和订阅要在账号后台的「管理账单」里取消，见 [账号与付款](/docs/account/)。


每个已付费且未绑定的席位各可领取一张安装码。两个空余付费席位可领两张码；未使用码作废或过期后可重领，仍受安装服务日额度限制，UTC 零点重置。

## 从另一台电脑给席位添加遥控器

目标电脑安装完成、绑定账号且在线后，在账户页找到它的席位卡，点「添加遥控器」。用通行密钥确认一次，手机扫码即可；无需去目标电脑终端设置批准口令或输入六位码。同一会话十分钟内免重复确认，二维码五分钟内只可添加一台设备。待批准设备也可在席位卡查看、批准；「恢复 / 启用定时任务」提供全部停下恢复与任务启用的主人批准。

默认允许账户页添加；目标电脑的主人可用 `agentj remote-pair off` 关闭。离线时不排队，开机后重试；旧版本按提示运行 `agentj update apply` 或从已有手机升级。新设备来源显示「经账户页添加」，其他遥控器收到通知。

账户页配对依赖签名控制平面。配对材料只以浏览器临时公钥加密回传，后端不保存明文；签名服务被攻破仍可能增加设备，关闭开关可拒绝此路径。批准口令仍只在本机散列保存，作为未绑定账号或离线、本机批准的备选。


## macOS 系统版本

先试运行 `opencode --version`（或所选 Agent 的 `--version`）；能正常运行就能继续安装，不按 macOS 版本号拦截。一键安装也会实际试运行它下载的固定版 OpenCode。如果看到 `dyld: Symbol not found: _ubrk_clone` 和 `/usr/lib/libicucore.A.dylib` 后退出，才说明该二进制与系统库不兼容；PATH 或 npm 重装不能修复，请升级系统、换电脑，或用能正常运行的其他 Agent 按手动路线安装。一键安装优先从本站下载固定版本 uv，托管 Python 使用镜像，包依赖失败时重试镜像；旧预览下载路径已停用。


已安装 Agent J 的电脑也能使用 AJI 安装码：重新运行账户页的一键安装命令，会保留配置，只升级并绑定席位。也可把码放在权限为 0600 的文件中，运行 `agentj login --install-code-file <文件> --name <名字>`。AJI 码只能用一次；ajt_ 设置码只用于绑定已安装的电脑。绑定后到账户页添加遥控器，用通行密钥确认并扫码，无需在终端设置批准口令。

Intel Mac 安装和升级都会限制 `cryptography<49`。如果旧安装器报 `openssl-sys` 或找不到 OpenSSL，在 `uv tool install` 后加 `--with "cryptography<49"` 再试。

## 同一台电脑给第二个人安装

每人一个系统用户，各用自己的付费席位、安装码与手机。完整步骤见[同机多席位](/docs/multi-seat/)。
